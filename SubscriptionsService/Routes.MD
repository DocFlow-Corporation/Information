# Роуты Subscription Service

Базовый префикс сервиса - ***/subscriptions***

## 1. ***GET /catalog*** - Получение каталога подписок

## 2. ***POST /buy/{id подписки}*** - Покупка подписки

## 3. ***GET /subscriptions/user/(active или all или -)/{user_id}*** - Получение подписок конкретного пользователя с возможностью выбора статуса

## 4. ***GET /subscriptions/hassub/{user_id}*** - Проверка наличия активной подписки у пользователя
