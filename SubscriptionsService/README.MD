# Subscription Service

Данный сервис отвечает за следующий функционал:

- Предоставление каталога подписок (у нас всего одна :/ )
- Верификация покупки
- Предоставление информации о подписках того или иного пользователя


## 1. Предоставление каталога подписок

Обратившись по роуту ***GET /subscriptions/catalog*** , можно получить список текущих тарифов в виде списка, где ключ - название тарифа, а значение - массив параметров тарифа.

Пример:

```

{
  "Ultimate" => 
  [
    "price" => 40,
    "currency" => "USD",
    "description" => "Very cool subscription - buy it now!"
  ]
}

```

## 2. Верификация покупки


1) При нажатии "Оплатить" отрабатывает роут по типу ***POST /subscriptions/buy/{id подписки}***
2) Происходит редирект на платежку Ю-Каssа, которая возвращает статус оплаты - success/failure
3) Сервис обрабатывает полученный результат и уведомляет пользователя об этом - "Подписка успешно куплена" или "Ошибка проведения оплаты"

## 3. Получение информации о подписках пользователя

Обратившись по роуту ***GET /subscriptions/user/(active или all или -)/{user_id}***, можно получить информацию о подписках


## 4. Проверка наличия действительной подписки

Роут ***GET /subscriptions/user/current/*** позволяет проверить наличие активной подписки у пользователя на данный момент

Возвращает ответ по типу:

```
{
  "isActive" => true
}

```
