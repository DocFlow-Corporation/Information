# Основные бизнес-сущности Subscriptions Service


## 1. Plan - Тариф (тип подписки)

- Название
- Цена
- Описание
- Длительность подписки (в днях?)

Пример:

- "Premium"
- 2000р
- "Неплохой тариф для продвинутых пользователей"
- 365


## 2. Subscription - Купленная подписка

Именно купленная подписка - контракт с пользователем

- Дата покупки
- Дата окончания
- ID покупателя
- Тариф

Пример:

- 01.09.2026
- 01.09.2027
- 1234
- "Premium"
