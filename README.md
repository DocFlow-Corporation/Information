# Information

Проект "DocFlow" состоит из семи основных микро-сервисов:

- Document Service
- Identity Service
- Notification Service
- Patrners Service
- Signing Service
- Workflow Service
- Templates Service


***Подробную информацию о каждом сервисе можно найти в отдельной директории с названием сервисе***

## 1. Document Service - Реестр документов

Данный сервис отвечает за следующие аспекты приложения:

1) Генерация документов
2) Изменение и версионирование документов

## 2. Templates Service - Шаблоны документов

Данный сервис предоставляет шаблоны для генерации документа.

Функционал сервиса:

1) Хранение и предоставление базовых шаблонов
2) Создание кастомного шаблона для генерации документа

## 3. Workflow Service - Передача и согласование документов

Данный сервис отвечает за следующий функционал:

1) Отправка документов другим пользователям
Владелец документа может отправить его другим пользователям для ознакомления или подписания
2) Изменение статуса документа

Основные статусы документа: Draft, In Process, Approved/Declined, Signed


## 4. Signing Service - Электронная подпись документов

Данный сервис позволяет генерировать электронную подпись и подписывать ею документ


## 5. Notification Service - Уведомления от приложение

Данный сервис покрывает следующую часть функционала:

1) Отправка Email уведомлений
2) Создание уведомлений внутри приложения

## 6. Identity Service - Регистрация, авторизация и идентификация пользователя

Данный сервис покрывает следующую часть функционала:

1) Регистрация пользователя
2) Авторизация пользователя
3) Определение прав пользователя

## 7. Partners Service - Продажа подписок

Данный сервис ответственен за предоставление подписок, покрывает следующий функционал:

1) Хранение всех типов подписок
2) Полный цикл продажи подписки
